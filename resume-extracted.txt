E X P E R I E N C E
Forward Deployed Engineer Intern - Tiny Magiq Innovations  Mar 2026 – Present | Chennai
Key Project: Centralize - Centralized OCR and Document Intelligence Platform (Client: Team Everest NGO)
Requirement:Team Everest NGO runs scholarship programmes for students. Students submit hand-filled
scholarship application forms, and volunteers verify each student by visiting the student's home, asking the
verification questions in person, filling the verification form by hand - covering the student's family background and
situation - and uploading it. All forms arrive as digital uploads in PDF and image formats, and the handwritten data
had to be extracted and saved into a database. Before this application, the client's team typed each form's data
into the database manually; the platform automated that manual entry end to end.
Phase 1:Built an OCR pipeline that auto-fetches new applications from Zoho Creator when the server starts,
extracts data from the PDF and image uploads, and pushes it into Supabase; built a minimal frontend with a split
view to verify and edit extracted data against the form.
Client-embedded delivery:First built a full understanding of the client's needs and the complete requirement
picture, then worked on-site at the client office twice a week with their team to improve each process step by step.
Phase 2 (evolved requirement):Rebuilt the tool into a centralized OCR web application supporting any form -
upload from the UI, per-document and overall batch status, export feature, Admin/User role-based access control
(RBAC), and audit logs of user actions.
Platform features built:Batch upload with a pipeline progress UI, auto-retry for failed tasks, recovery option for
deleted files, Excel export with selective files and columns, and most settings configurable from the frontend UI
without code changes.
UI design:Designed the interface to match the client's existing application, as they requested — making the
platform familiar, much simpler, and easier for their team to use.
Template approach:Uploading a sample form in the template section automatically creates its layout and
connects it to the database with its table and columns in a single click; templates are easy to edit or delete and are
managed only by Admin users.
Validation support:Every extraction shows a confidence percentage for the extracted data, so reviewers can
easily spot low-confidence results and cross-verify them.
Metrics feature:Surfaces repeated mistakes in a specific form or a specific field, so error patterns can be traced
easily and improved in future.
Backend hardening:Celery workers for background processing, with watchdogs that monitor and retry failed
processes; Redis as the message broker; Lua-scripted rate limiting so AI model calls never hit 429 errors.
Scale and results:Batches scaled from 10-15 PDFs to 108 files (100 images processed in under 8 minutes);
deployment consolidated from 17 Docker services to 5 containers on a single PostgreSQL database; observability
with Grafana and Sentry.
Deployment and handover:Advised the client on VM deployment for their Azure environment, where they will run
the application internally, embedded in their portal; answered their questions on whether the application can be
deployed on a VM and what configuration it needs - specified a minimum of 4 GB RAM and 10 GB disk, plus the
installation requirements, and supplied these as part of the delivery. Validated the full deployment on a GCP VM
and gave the client a 30-day live access link that worked successfully; handed over the full working flow with step-
by-step documentation and a formal project closure (Nov 2026).
